# 이상현상 설계

이상현상의 설계 원칙, 분류 체계, 목록, 데이터 스키마. 목록은 계속 추가한다.
(왜 이것이 무서운가의 이론적 근거: [fear-cognition.md](./fear-cognition.md) —
특히 §1 예측 오류: 이상현상 = "학습된 정상의 미세 위반". 정상 3회 노출 후 변형 등장 원칙 준수)

## 설계 원칙 (위반하면 추가 금지)

1. **명확성** — 보면 "아!" 하고 무릎을 쳐야 한다. 픽셀 틀린그림찾기 금지.
   - 공정: 간판 글자가 바뀜, 셔터가 열림, 그네가 혼자 흔들림
   - 불공정: 벽돌 개수가 다름, 원경의 미세한 색 차이
2. **일상성** — 한국의 밤 골목에서 실제로 있을 법한 사물의 어긋남이어야 한다.
   기괴한 크리처보다 "아까랑 그림자 방향만 다른 사람"이 더 무섭다.
3. **1회 학습** — 한 번 당한 이상현상은 다음부터 반드시 알아볼 수 있어야 한다.
4. **깜놀 총량제** — 점프스케어형은 전체의 10% 이하, 밤 4~5에만 배치.
5. **온도 우선** — 귀갓길 전용 이상현상은 판정이 아니라 "빠른 인지 + 회피"로 처리 가능해야 한다.

## 분류 체계

| 분류 | 코드 | 설명 | 예시 |
|---|---|---|---|
| 사물 | OBJ | 정적 사물의 상태 변화 | 셔터, 간판, 주차 차량, 우산 |
| 텍스트 | TXT | 글자·문서의 변화 | 전단지 전화번호, 간판 오탈자, 시세표 |
| 조명 | LGT | 빛의 어긋남 | 가로등 깜빡임 패턴, 켜진 세탁소, 꺼진 편의점 |
| 인물 | HUM | 사람 형태의 어긋남 (밤 3+) | 같은 자리의 대리기사, 신발 없는 승객, 그림자 방향 |
| 공간 | SPC | 지형·구조의 어긋남 (밤 4+) | 늘어난 골목 길이, 사라진 모퉁이, 반대로 걸린 표지판 |
| 소리 | SND | 청각 단서 (시각 확인 필요) | 끊기는 발소리, 한 박자 늦는 메아리 |
| UI | MTA | 메타/UI 어긋남 (밤 4~5, 아껴 쓰기) | 온도 게이지 역행, 자막 오염, 커뮤니티 앱 거짓 힌트 |

## 데이터 스키마 (JSON)

콘텐츠는 코드 수정 없이 데이터로 추가한다.

```jsonc
{
  "id": "A-004",
  "night": 1,              // 등장 시작 밤
  "segment": 2,            // 배치 구간 (1~5)
  "category": "OBJ",
  "trip": "outbound",      // outbound | return | both
  "detect": "visual",      // visual | audio | ui
  "jumpscare": false,
  "apply": {               // 씬에 가하는 변경 (엔진이 해석)
    "target": "laundry_shutter",
    "state": "half_open",
    "light": { "target": "laundry_interior", "on": true }
  },
  "hint": null             // 연계 힌트 ID (규칙형 괴담일 때)
}
```

## 규칙형 괴담 (이상현상과 별개 축)

밤 2부터 등장하는 명시적 규칙. 힌트 텍스트 + 위반 조건 + 결과로 구성.

```jsonc
{
  "id": "R-001",
  "night": 2,
  "hintSource": "convenience_door",   // 힌트가 붙는 위치
  "hintText": "오늘은 정류장에 앉아 계신 분께 인사하지 마세요.",
  "violation": "interact:bus_stop_person",
  "result": "reset_to_start",
  "authoredAt": "today"               // 밤 4: 'yesterday' 힌트 = 만료된 규칙
}
```

## 배치 규칙 (2026-07-29 추가 — A-013 입간판 사례에서 도출)

이상현상은 "존재"가 아니라 **"보이는 것"** 이 구현 완료 기준이다. 아래 셋을 모두 만족해야 한다.

1. **광원 안쪽** — 구간 포인트라이트(가로등) 사거리 안에 둔다. 안개(FogExp2)는 거리 제곱으로
   먹히므로, 구간 후반(70% 이후)에 어두운 색 사물을 두면 사실상 존재하지 않는 것과 같다.
2. **관찰 시간 확보** — 판정 지점(구간 끝 갈림길)에서 최소 10m 앞에 배치. 갈림길 바로 옆에
   두면 보고 판단할 틈이 없다.
3. **실루엣 대비** — 벽 색(`#20263a`대)과 명도가 겹치는 사물은 안 보인다. 정상/이상 상태의
   차이는 각도 몇 도가 아니라 **실루엣이 바뀌는 수준**이어야 한다.

## 밸런싱 메모

- 구간당 이상 발생 기본 확률: 초안 40% → **새벽이 깊어질수록(경과 시간에 따라) 상승**
  (우회 남발 억제 장치, game.md 판정 시스템 참고) → 플레이테스트로 조정
- 같은 이상현상은 한 세션에 1회만 재사용 금지
- 오는 길은 "가는 길에 이상 없던 구간 중 1곳"에만 신규 이상 배치 (기억 테스트)
- 샛길은 본길보다 통과 시간 1.5~2배 (오는 길 온도 비용의 근거) — 수치는 테스트로 확정
