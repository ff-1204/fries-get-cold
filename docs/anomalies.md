# 이상현상 설계 — 밤의 골목에만 있는 것

핏자국, 백골, 창문의 얼굴, 그네에 앉은 형체. **밤의 골목에 있어서는 안 되는 것들.**

⚠ **이 문서는 새 설계 기준이다** ([game.md](./game.md) — 동사는 걷기 하나).
지금 라이브 빌드에는 아직 클릭 판정이 있다 — 그쪽은 [spec.md](./spec.md)가 적는다.

---

## ⭐ 이상현상은 판정 대상이 아니다

**아무것도 하지 않는다.** 쫓아오지 않고, 붙잡지 않고, 짚을 수 없고, 사라지지 않는다.
쳐다봐도 벌이 없고 눈을 돌려도 상이 없다. **처리할 수 없다.**

그것들이 하는 일은 하나다 — **플레이어를 멈춰 세우는 것.**
그리고 멈춰 있는 동안 골목이 자란다.

| | 이전 설계 | 지금 |
|---|---|---|
| 흔적 | 4.5m까지 다가가 **클릭하면 사라진다** | 그냥 있다. 지날 때까지 계속 있다 |
| 사람 형체 | 2.2초 이상 보면 **붙잡힌다** | 그냥 있다. 봐도 아무 일 없다 |
| 대가 | 판정 실패 → 늘어남 | **멈춘 시간** → 늘어남 |

이 교체가 만드는 차이:

- **공포를 지우는 버튼이 없어졌다.** 이전에는 무서운 것을 클릭하면 없어졌다 —
  공포 게임이 플레이어에게 공포 제거 버튼을 쥐여주고 있었다
- **배울 것이 없어졌다.** 규칙을 모르는 사람에게도 첫 밤부터 똑같이 작동한다.
  긴장의 출처가 지식이 아니라 **반사**이기 때문이다
- **억울한 실패가 사라졌다.** 처벌 판정이 없으니 공정성 계산도, 경고 유예도,
  되돌릴 여지도 필요 없다. 남은 것은 카운터 하나뿐이고 그건 거짓말하지 않는다

⭐ **그래서 이 문서에는 규칙표가 없다.** 통과 조건도, 금기 목록도, 위반 판정도 없다.
이상현상에 관해 결정할 것은 딱 하나 — **무엇을, 어디에 세울 것인가.**

## 무엇이 좋은 이상현상인가

판정이 없어진 지금, 좋고 나쁨의 기준은 하나로 줄었다 —
**보는 순간 걸음이 멈추는가.** 아래는 그것을 만드는 방법들이다.

### 잘 듣는 것

- **늘 있던 것 위에 얹는다** — H-012(담 위), H-013(오토바이), H-016(벤치).
  새 물건이 나타나는 것보다, 익숙한 자리에 있어서는 안 되는 것이 있는 편이 더 어긋난다
- **정상의 반복을 무기로 쓴다** — H-011(닫힌 셔터 다섯 중 하나만 빛이 샌다),
  H-015·H-017. 학습된 정상이 두꺼울수록 위반 하나가 도드라진다
- **시선을 되받는다** — H-003(얼굴), H-006(눈). 자체 발광이라 어둠에 둘 수 있어
  배치도 자유롭다. **되받는 시선은 사람을 확실히 멈춰 세운다**
- **부재** — 늘 있던 프롭 하나를 **지운다.** 신규 지오메트리 0이고,
  정상이 두꺼운 테마 2·5에서 특히 강하다. 아직 안 쓴 수법이다
- **다수화** — 하나였는데 셋이다. 동시 등장 수를 올리면 무료로 나온다

### 정물이다 — 움직이지 않는다

**이미 그렇게 있다.** 등장 트윈도, 추격도, 혼자 흔들리는 그네도 없다.
가장 무서운 것은 달려드는 것이 아니라 **아까부터 거기 있었던 것**이다.

정물성은 새 설계에서 더 중요해졌다. 판정이 없으니 이상현상이 주는 압력은
**그 자리에 계속 있다는 사실** 하나뿐이고, 움직이는 순간 그게 이벤트가 되어 버린다.

### 애매한 것을 이제 만들 수 있다

우비인지 사람인지, 마네킹인지 형체인지 **끝까지 알 수 없는 것.**

이전 설계에서는 이것을 만들 수 없었다 — 조준만 해 보면 판정 반응으로 정체가 갈렸고,
게다가 헷갈린 대가가 붙잡힘이라 "애매하게 만들고 헷갈린 값을 물리는" 구조가 됐다.

**클릭이 사라지면서 둘 다 풀렸다.** 이제 애매한 것은 끝까지 애매하고,
헷갈려도 아무 일도 일어나지 않는다 — 그저 **한 번 더 쳐다보게 될 뿐이다.**
그리고 그 한 번이 골목을 자라게 한다.

⚠ 다만 단서는 정적인 형태여야 한다(움직임으로 정체를 드러내지 않는다). 쓸 수 있는 것:
**다리가 없다 · 받침대가 있다 · 관절 이음매 · 개수가 하나 더 많다 · 있을 수 없는 자리.**
그림자·흔들림·반사상은 렌더러에 없거나 정물성과 어긋난다.

## 배치 — "존재"가 아니라 "보이는 것"이 완료 기준이다

판정이 없어진 뒤 배치는 **더** 중요해졌다.
이전에는 안 보이면 놓쳐서 늘어났지만, 지금은 안 보이면 **아무 일도 일어나지 않는다.**
보이지 않는 이상현상은 없는 것과 같다.

1. **광원 안쪽** — 구간 포인트라이트(가로등, `z = -L*0.45`) 사거리 안에.
   예외: 자체 발광형(눈·얼굴)은 스스로 빛나므로 어둠에 둘 수 있다
2. **관찰 시간 확보** — 구간 출구에서 최소 10m 앞에.
   ⭐ **다가갈 거리를 계산에 넣을 필요가 없어졌다** — 이제 다가가지 않기 때문이다.
   대신 **걸어가면서 보이는 시간**이 전부다
3. **실루엣 대비** — 어두운 형체는 밝은 배경(가로등 풀·유리) 곁에,
   밝은 것(백골)은 어두운 배경에

**②는 눈이 아니라 레이캐스트로 검증한다** — `?a=<effect>`로 고정하고
`window.__fries.occlusion()`을 구간의 여러 지점에서 호출한다.

⚠ **가림 검사는 '밝기'를 재지 않는다.** 셋 중 레이캐스트가 답하는 것은 ②뿐이다.
5/5로 통과하고도 광원에서 9m 밖이라 화면에서는 아무것도 안 보인 이상현상이 있었다 —
**통과해도 스크린샷을 한 장 본다.** 프롭을 대량 추가한 뒤에는 반드시 돌린다.

## 골목의 치수 (알고 쓰면 되는 사실)

금지 목록이 아니라 재료의 크기다.

| | |
|---|---|
| 구간 36m × 통행 폭 ±3m × 벽 높이 7m | 좌우 여유가 2~3m뿐 |
| 직진뿐, 갈림길 없음 (출구 = 끝벽 중앙 개구부 반폭 1.4m) | 길찾기·미로는 애초에 다른 게임이다 |
| 구간 전환 = 다리 밑 터널 한가운데의 암흑 | **구간을 넘어 이어지는 존재는 시스템이 지운다** |
| 광원은 구간당 가로등 하나 (+ 테마별 자체 광원) | 밝은 곳이 곧 무대다 |
| 그림자 렌더링 없음 · 반사 없음 | 그림자·반사상을 단서로 쓸 수 없다 |
| 구간 3(놀이터)은 펜스와 벽 사이가 0.85m | 실물 프롭이 못 들어간다. 담장 쪽으로만 늘린다 |

**모바일 화면에서 3초 안에 알아볼 수 있는가**가 명확성의 기준선이다
([responsive-design.md](./responsive-design.md) §6).

⚠ **유혈은 흔적까지만** — 핏자국·끌린 자국까지다. 출혈 장면, 신체 훼손, 시체의 직접 묘사,
매달린 실루엣은 쓰지 않는다. 이것은 취향이 아니라 법적 준수 항목이다
([design-principles.md](./design-principles.md) §법적 준수).

## 데이터 스키마 (`src/data/anomalies.json`)

```jsonc
{
  "id": "H-001",            // 이 문서 표의 ID와 일치
  "night": 1,               // 등장 시작 밤
  "segment": 1,             // 배치 구간 1~5 / 0 = 전 구간 (스폰 앵커 랜덤)
  "effect": "blood_trail",  // world/effects.ts 핸들러 키 = ?a= 디버그 키
  "outboundOnly": true      // 선택 — 귀갓길에 보이지 않는 사물이면 지정
}
```

**새 설계에서 사라지는 필드 셋**:

| 필드 | 왜 사라지나 |
|---|---|
| `rule` (`gaze`/`avert`) | 판정이 없으니 대응 구분도 없다 |
| `untilNight` | 규칙 배신 전용 필드였다 |
| `reveal` | "무엇이 이상했는지" 사후 자막 — **놓침이라는 개념이 없어졌다** |

`category`(OBJ/HUM/LGT/…)는 남긴다. 판정에는 안 쓰지만
**분포를 보는 눈**으로는 여전히 쓸모 있다 (형체만 다섯 구간에 깔리면 단조로워진다).

**선택 로직** — 현재 구간·현재 밤으로 풀을 거르고, 직전 이상현상은 제외한다(연속 방지).
첫 밤 첫 구간은 정상으로 두어 **비교 대상**을 먼저 준다.

## 추가하는 절차

1. **무엇을, 어디에** 정한다 — 위 "잘 듣는 것"에서 고르고, 분포의 구멍을 본다
2. `world/effects.ts`에 핸들러를, `anomalies.json`에 한 줄을 더한다
3. **보이는지 확인한다** — `?a=<effect>` + `occlusion()` 여러 지점 + **스크린샷 한 장**
4. `scripts/verify.mjs`의 cases에 등재하고 이 문서 표에 줄을 더한다

**코드를 열어야 하는 것은 2번의 핸들러 하나뿐이다.** 그 밖에 판정·밸런스·스테이지 파일을
건드려야 한다면 설계가 어긋난 것이니 멈추고 본다.

## 밸런싱

이상현상이 늘어남을 직접 부르지 않으므로 **`balance.ts`의 모델은 이상현상과 무관해졌다.**

- 구간당 등장 수를 올리면 멈출 기회가 늘고, 밤이 길어진다
