# 이상현상 설계 — 밤의 골목에만 있는 것

**이상현상 = 있어서는 안 되는 것의 출현.** (v0.9.0 확립, v0.11.0까지 유지 — game.md 결정 기록)
구 문법(일상 사물의 미세한 어긋남)은 퇴역했다. 이상현상은 전부 **명백한 비일상** —
핏자국, 백골, 형체, 어둠 속의 눈 — 이며, "밤의 골목은 다른 무언가와 겹쳐진다"는
서사(story.md §3)가 이를 정당화한다. 첫날 퇴근길(튜토리얼)에는 등장하지 않는다.
※ 문서 ID의 H는 v0.9.0 명명(hallucination)의 유산 — 데이터 호환을 위해 유지.

## 통과 규칙 2축 (v0.11.0) — 이 게임의 판단

명확한 것들 사이에서 **대응이 갈린다.** 무엇인지 알아보는 것이 곧 실력이다.

| 부류 | `rule` | 대응 | 어기면 |
|---|---|---|---|
| **흔적·사물** (OBJ) | `gaze` | 4.5m 이내로 다가가 **직시** → 사라진다 | 안 보고 나가면 **접힘** |
| **사람 형태** (HUM) | `avert` | **보지 않는다.** 눈을 돌리고 지나간다 | 시선축 12°·11m 안에 2.2초 담으면 **붙잡힘**(=접힘). 짚으면 즉시 |

- 관례는 OBJ=gaze / HUM=avert 지만 **최종 결정은 데이터**(`rule` 필드)다 — 밤 5의
  규칙 배신(외면해야 했던 것을 직시해야 하는 한 번)은 이 필드로 표현한다
- 응시 공정성 4요소: ① 거리·각도 제한 ② 0.4초 경고 자막 + 정적 + 시야 조임
  ③ 눈을 떼면 2.5배속 회복 ④ 통행선 옆을 스쳐 지나가는 것으로는 걸리지 않는다
- **avert는 확인 의무가 없다** — 지나치는 것이 정답이므로 접힘 판정에서 제외된다

- 콘텐츠 소스: **`src/data/anomalies.json`** (스키마는 아래) — 이 문서의 표는 설계·현황판
- 확인 방법: URL에 `?a=<effect>` — 해당 구간에 도달하면 강제 등장 (`?a=none` = 항상 정상)
- 구 일상 어긋남 14종(A-001~A-015)은 **풀에서 퇴역** — 코드 핸들러·정상 사물은 배경으로
  잔존한다 (effect 키는 유지되나 JSON에 없어 등장하지 않음). 목록은 git 이력 참조

## 이상현상 추가하는 법 (3단계)

1. **이 문서의 표에 행 추가** — 무엇이 나타나는가, 분류, 통과 규칙(직시/외면), 등장 밤. 아래 원칙 4개를 먼저 통과시킨다.
2. **`src/data/anomalies.json`에 데이터 추가.** 기존 effect를 재사용하면 여기서 끝.
   새로운 시각물이 필요하면 `src/world.ts`에 사물 + effect 핸들러(visible 토글) 추가.
3. **`?a=<effect>`로 직접 확인** — 명확성 자가 테스트: "3초 안에 '있어서는 안 되는 것'임을
   아는가?" + 아래 배치 3원칙 점검 + verify.mjs cases에 스크린샷 케이스 추가.

## 설계 원칙 (위반하면 추가 금지)

1. **명확성** — 보면 "저건 아니지" 해야 한다. 배경과 헷갈리는 미묘함 금지.
   명백해서 무섭다 — 난이도는 발견이 아니라 **대응의 판단**(직시할 것인가, 외면할 것인가)에 있다.
2. **정물성** — 움직이며 쫓아오지 않는다. "이미 그렇게 있는" 것이 무섭다
   (등장 트윈 금지, 추격 없음 — 크리처가 아니라 괴담의 존재다).
3. **흔적까지만** — 피는 자국·끌림까지. 출혈 장면, 신체 훼손, 시체의 직접 묘사,
   자살 암시 형상(매달림 등)은 쓰지 않는다 (design-principles §1·§1-1).
4. **깜놀 총량제** — 점프스케어형은 전체의 10% 이하, 밤 4~5에만.

## 배치 3원칙 (2026-07-29 도출 — 컨셉 전환 후에도 유효)

"존재"가 아니라 **"보이는 것"** 이 구현 완료 기준이다 — 외면 부류도 마찬가지다.
보이지 않으면 피할 기회조차 없다.

1. **광원 안쪽** — 구간 포인트라이트(가로등) 사거리 안에 둔다. 예외: 자체 발광형(눈, 얼굴)은
   스스로 빛나므로 어둠에 둘 수 있다 — 가장 확실한 식별 보장.
2. **관찰 시간 확보** — 구간 출구에서 최소 10m 앞에 배치. 직시하러 **다가갈 거리**(4.5m
   판정)까지 계산에 넣는다. 검증: `window.__fries.occlusion()`(?a= 한정) —
   구간을 걸으며 호출해 `clear: true`가 유지되는지 본다 (프롭에 가리면 false).
3. **실루엣 대비** — 어두운 형체는 밝은 배경(가로등 풀·유리) 곁에, 밝은 것(백골)은
   어두운 배경에. 흰 형체/발광이 가장 확실하다.

## 데이터 스키마 (`src/data/anomalies.json`)

```jsonc
{
  "id": "H-001",            // 이 문서 표의 ID와 일치 (H = 유산 명명, 아래 주석 참조)
  "night": 1,               // 등장 시작 밤 (해금)
  "segment": 1,             // 배치 구간 1~5 / 0 = 전 구간 (스폰 앵커 랜덤)
  "category": "OBJ",        // OBJ|LGT|TXT|HUM|SPC|SND|MTA (아래 분류 체계)
  "rule": "gaze",           // gaze = 직시해야 사라짐 / avert = 보면 붙잡힘 (v0.11.0 판단 축)
  "effect": "blood_trail",  // world.ts 핸들러 키 = ?a= 디버그 키
  "reveal": "…바닥의 검붉은 자국은, 원래 없던 것이었다.",  // 접힘 직후 암시 문구 (공정성)
  "outboundOnly": true      // 선택 — 귀갓길에 보이지 않는 사물이면 지정
}
```

선택 로직(main.ts rollSegment): 현재 구간·현재 밤으로 풀을 거르고, 직전 이상현상은 제외
(연속 등장 방지). 밤 1 첫 구간은 항상 정상, 밤 1 귀갓길에 최소 1회 보장 (온보딩).

| 사물 | OBJ | 있어서는 안 되는 물체·흔적 | 직시 | 밤 1 | 핏자국, 백골, 손자국, 끌린 자국 |

## 규칙형 괴담 (존재별 예외 규칙 — 밤 3부터, M3)

기본 2축(직시/외면) 위에 존재별 예외를 얹는다 — "멈추면 안 되는 밤", "인사하면 안 되는 것",
밤 5의 규칙 배신(외면 대상을 직시해야 하는 한 번). 힌트 텍스트 + 위반 조건 + 결과로 구성.

## 밸런싱 메모

- 구간당 이상현상 발생 기본 확률 40% + 밤이 깊을수록 상승 (`config.ts CONFIG`)
- 같은 이상현상 연속 등장 금지 (구현됨 — 접힘 반복 구간에서 특히 중요)
- 비용 (v0.11.0): 빈 지적 = 깊이 +1 (즉각 가로등 감광), 연타는 쿨다운 0.6초.
  외면 위반(응시 2.2초·손가락질) = 붙잡힘 = 접힘과 동일.
  접힘 = 깊이 +2. 깊이 한계 6 = 입구 리셋 — 접힘 3회 / 빈 의심만 6회.
  `npm run verify:sim`(모델)·`verify:balance`(E2E)로 검증됨
- 범주 로테이션: 같은 범주(OBJ/HUM)의 연속 등장을 피한다 (fear-cognition §4 습관화) — M3 예정
