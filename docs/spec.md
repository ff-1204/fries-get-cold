# 현재 빌드 명세 — 규칙·콘텐츠 현황

**v0.4.0 (2026-08-02) 기준.** 라이브 빌드에 실제로 들어 있는 것만 적는다 —
기획·로드맵은 [game.md](./game.md), 버전별 상세 이력은 CHANGELOG.md.
릴리즈마다 이 문서를 실빌드와 대조해 갱신한다.

## 1. 목표와 승리 조건

- **밤의 목표**: 집에서 출발해 골목 구간들을 지나 **버거집에 도착**하면 그 밤 완주.
  도착하면 감자튀김을 사고, 귀가는 컷으로 처리 → 시식 연출 → 다음 밤.
- **완주 등급** (시식 서사 — 접힘 횟수가 결정):

  | 접힘 | 시식 문구 | 기록 |
  |---|---|---|
  | 0회 | "아직 따뜻하다 … 바삭하다" | crispy (노미스) |
  | 1~2회 | "조금 식었다 … 미지근하다" | lukewarm |
  | 3회+ | "다 식었다 … 눅눅하다" | soggy |

- **최종 엔딩은 아직 없다** — 밤은 무한히 이어지며(밤 6부터 텍스트는 밤 5 것을 반복),
  기획된 엔딩 3종(두고 나온다 / 가져온다 / 히든 "포장 주문" = 전 밤 노미스)은 M3에서
  밤 5와 함께 구현 예정. 현재 빌드의 "승리"는 **밤 단위 완주**다.
- **패배(게임 오버)도 없다** — 오답은 죽음이 아니라 연장(§2 접힘), 깊이 한계는
  같은 밤 재시작(§3 soft fail). 죽음·유혈 묘사 없음 (15세 원칙).

## 2. 코어 규칙 — 판정과 접힘

- 밤은 구간 5개로 시작한다 (HUD "1/5 — 원룸 골목").
- 구간마다 **이상현상 유/무**가 배정된다 (확률: 기본 0.4 + 경과 1분당 0.06, 상한 0.8.
  밤 1 첫 구간은 항상 정상, 밤 1 후반까지 무이상이면 강제 등장 — 온보딩 보장).
- 구간 끝 갈림길에서 선택한다:

  | 구간 상태 | 본길 | 샛길 |
  |---|---|---|
  | 정상 | ✅ 전진 | ⚠ 전진 + **깊이 +1** (과잉 경계 — "가로등이 하나, 어두워졌다") |
  | 이상 | 🌀 **접힘** | ✅ 전진 (정당 우회 — 무비용) |

- **접힘** = 오답의 결과. 같은 테마 구간이 미묘하게 달라진 채 반복되고,
  총 구간 수가 +1 (카운터 "3/5" → "4/6" — 걸음은 소비됐는데 남은 거리가 안 줄었다),
  깊이 +2. 접힘 순간: 카운터 페이드 교체 + reveal 자막(무엇이 어긋났었는지) +
  사운드 드랍 + 반복 구간 입구 바닥의 분필 원.

## 3. 깊이 — 유일한 자원

- 깊이는 숫자로 표시되지 않는다. **가로등 밝기가 게이지다**: 깊이 0~5에서
  가로등 22→16→11→7→4→2 (앰비언트·안개도 연동해 어두워진다).
- **깊이 6 도달 = soft fail**: 암전 → "정신을 차려 보니, 골목 입구다" → 같은 밤을
  처음부터 (깊이·구간 수 리셋, 밤 번호 유지). 접힘 3회 또는 과잉 경계만 6회면 도달.

## 4. 구현된 콘텐츠

**구간 테마 5종** (구조 차별화 완료): 원룸 골목 / 상가 골목 / 놀이터 옆길 / 정류장 앞 /
먹자골목 입구 — 프리팹 1개 + 테마 전환 방식, 구간당 도보 40초 내외 (무결점 편도 43.5초).

**이상현상 13종** (전부 구현·가시성 검증 — 상세는 [anomalies.md](./anomalies.md)):

| 구간 | 이상현상 (effect) |
|---|---|
| 1 원룸 골목 | 우산(umbrella) · 센서등 점등(sensor_on) · 붉은 창문(window_red) · 전단지 자릿수(flyer_digits, 밤2) |
| 2 상가 골목 | 세탁소 반열림(laundry_open) · 간판 점등(sign_lit) · 시세표 "급구"(realty_urgent, 밤2) |
| 3 놀이터 옆길 | 그네 흔들림(swing) · 가로등 깜빡임(lamp_flicker) · 공 이탈(ball_out) |
| 4 정류장 앞 | 양쪽 빨간불(traffic_red) |
| 5 먹자골목 입구 | 입간판 회전(sign_turn) · 간판 오탈자 "24시간요"(shop_typo, 밤2) |

**연출·흐름**: 프롤로그(이불 속 배달 앱, 첫 시작만) → 타이틀 → 밤 시작 모놀로그(5종) →
걷기/판정 → 버거집 → 귀가 컷 → 시식(한 입×2 + 밤별 에필로그 5종, Peak-End) → 다음 밤.

**플랫폼·설정**: PC(포인터락+WASD+Shift 달리기) / 모바일(반분할 터치), 밝기·소리 설정,
기기 내 저장(localStorage — 밤·기록·설정, 서버 전송 없음), 뒤로가기=일시정지,
단일 파일 오프라인 빌드(play-local.html). 에셋 0 (프리미티브+캔버스 텍스처+프로시저럴 사운드).

## 5. 아직 없는 것 (로드맵 M3~M4)

- 밤 2~5의 고유 규칙(커뮤니티 앱·힌트·모순/거짓 힌트), 밤별 세트피스 5종
  (밤 4 "골목의 호의", 밤 5 귀갓길 반전 포함), 엔딩 3종, 이상현상 30종+ 확장(깊이 해금),
  접힘 변주 심화(프롭 변주), 사운드·조명 폴리시.
- 검증 잔여: 직접 처음부터 플레이(무설명 학습 확인), 모바일 실기기 확인.

## 6. 검증 도구 (개발자용)

- `?a=<effect>` — 해당 구간에서 이상 고정 (`?a=none` = 항상 정상)
- `npm run verify:sim` — 깊이 모델 시뮬레이션 9건 (<1초, 브라우저 불요)
- `npm run verify:balance` — E2E 실측 3케이스 (무결점 밤 / 접힘 3회→입구 리셋 / 정당 우회)
- `npm run verify:shots` — 이상현상 정상/이상 쌍 + 테마 + 접힘 시각 요소 스크린샷 18장
