# 현재 빌드 명세 — 규칙·콘텐츠 현황

**v0.11.22 (2026-08-03) 기준.** 라이브 빌드에 실제로 들어 있는 것만 적는다 —
기획·로드맵은 [game.md](./game.md), 버전별 상세 이력은 CHANGELOG.md.
릴리즈마다 이 문서를 실빌드와 대조해 갱신한다.

## 1. 목표와 승리 조건

- **게임은 언제나 귀갓길이다.** 가는 길은 컷 — FF-1204에서 튀김을 먹고 나오면,
  거기서부터 **집까지 걸어서 도착하면** 그 밤 완주. 목적은 하나:
  괴담의 존재들을 피해서 집에 가는 것.
- **첫날(밤 1)만 예외로 퇴근길 튜토리얼이 앞에 붙는다** — 힘든 하루의 끝, **정류장(4/5)에서
  시작해 먹자골목 입구(5/5)까지 두 구간만** 걷는다 (약 21초. 위협·비용 없음).
  **정류장 부스 곁에서 시작**하고, 저 앞 먹자골목 입구에 걸린 개업 현수막
  (FF-1204 · XXXXL 감자튀김)을 보고 걸음을 돌린다 →
  가게 도착·첫 도장은 컷 → "나와 보니, 깜깜하다" → 밤 1 귀갓길(본게임 시작).
  **자막은 걸음에 맞춰 다섯으로 나뉜다** — 정류장 "힘든 하루였다" → 신호등 앞 "현수막이 보인다"
  → 횡단보도를 벗어나며 "…XXXXL 감자튀김이다" → 골목 들어서기 직전 "…이건 못 참지"
  → 먹자골목 입구. 본 것을 본 자리에서 말한다.
- **완주 등급** (귀가 서사 — 접힘 횟수가 결정. 저장 키는 구 스키마 호환 유지):

  | 접힘 | 귀가 문구 | 기록 키 |
  |---|---|---|
  | 0회 | 🏠 곧장 왔다 | crispy (노미스) |
  | 1~2회 | 🏠 조금 돌았다 | lukewarm |
  | 3회+ | 🏠 한참 걸렸다 | soggy |

- **최종 엔딩은 아직 없다** — 밤은 무한히 이어지며(6밤+는 도장이 칸 밖에 찍힌다),
  기획된 엔딩 3종(두고 나온다 / 쿠폰을 쓴다 / 히든 "단골" = 전 밤 노미스)은 M3에서
  밤 5와 함께 구현 예정. 현재 빌드의 "승리"는 **밤 단위 완주**다.
- **패배(게임 오버)도 없다** — 실패는 죽음이 아니라 연장(§2 접힘), 깊이 한계는
  같은 밤 재시작(§3 soft fail). 죽음·유혈 '묘사' 없음 — 흔적(핏자국)까지만 (design-principles §1).

## 2. 코어 규칙 — 직시와 외면, 그리고 접힘

- 귀갓길은 구간 5개로 시작한다. 테마는 **역순**(먹자골목 입구 → … → 원룸 골목 = 집).
  HUD는 "밤 1 — 돌아가는 길 1/5 — 먹자골목 입구". 이동은 **직진뿐** — 갈림길도,
  뒤로 이전 구간으로 돌아가는 것도 없다.
- **첫날 퇴근길(튜토리얼)은 이상현상이 없다.** 무엇을 짚어도 무비용. 밝고 안전한 두 구간에서
  **정상 상태를 학습**하는 것이 역할이다 (v0.11.1: 규칙 표지판 철거 — 무설명 학습 복귀.
  v0.11.5: 5구간 → 2구간으로 단축, 심심한 시간의 비용을 줄였다).
- 밤 구간마다 **이상현상 0~복수 개**가 배정된다 (확률: 기본 0.4 + 경과 1분당 0.06, 상한 0.8.
  동시 개수 = 1 + 증식 단계. 밤 1 첫 구간은 항상 정상, 밤 1 후반까지 무이상이면 강제 등장).
  위치 자유형(그림자 사람)은 구간의 스폰 앵커 6곳 중 랜덤 지점에 출현.

### 통과 규칙 2축 (v0.11.0 — 이 게임의 판단)

| 부류 | 대응 | 어기면 |
|---|---|---|
| **흔적·사물** (OBJ, `gaze`) — 핏자국·백골·손자국·끌린 자국 | **다가가서(4.5m) 직시** (PC 클릭 / 모바일 탭) → 사라진다. 멀면 "…여기서는 확신이 안 선다"(무비용) | 안 보고 구간을 나가면 **접힘** |
| **사람 형태** (HUM, `avert`) — 창문의 얼굴·그네의 형체·어둠 속 눈·정류장의 형체·그림자 사람 | **보지 않는다.** 눈을 돌리고 그냥 지나간다 (확인 의무 없음) | 시선축 12°·11m 안에 **2.2초** 담으면 **붙잡힘**(=접힘). **짚으면 즉시** |

- **응시 공정성 4요소**: ① 거리·각도 제한 ② 0.4초에 경고 자막("…보면 안 된다") + 정적 +
  시야 조임 ③ 눈을 떼면 2.5배속 회복 ④ 통행선 옆을 스쳐 지나가는 것으로는 걸리지 않는다
- **엉뚱한 것을 짚음(빈 지적)** = 깊이 +1, 그 자리에서 가로등이 어두워진다. 쿨다운 0.6초
- **접힘**(놓침·붙잡힘 공통) = 같은 테마 구간이 미묘하게 달라진 채 반복 +
  총 구간 수 +1 (카운터 "3/5" → "4/6") + 깊이 +2 + **증식**(이후 구간 동시 이상 수 +1,
  1→2→3 상한). 접힘 순간: 카운터 페이드 교체 + reveal 자막 + 사운드 드랍 + 바닥의 분필 원

### 차도 — 신호등 (구간 4, v0.11.7)

- 구간 4에만 **열린 교차로**가 있다 (다른 테마는 벽이 메워져 있다).
  보행신호등은 건널목 양 끝에 하나씩 서로 반대를 본다 — **길 건너 것만 등화가 보인다**
  (적색 위 / 녹색 아래라 색각과 무관하게 위치로도 읽힌다).
  보행 신호 주기 9초: **초록 3.5s → 점멸 2.5s → 빨강 3.0s**
- **규칙: 빨간불이 되면 차가 한 대 지나간다** (세계의 규칙 — 위반과 무관하게 매 주기).
  그때 길 위에 있으면 **치임 → 접힘**(암전 → 같은 구간 반복 + 깊이 +2).
  방향은 주기마다 좌↔우 번갈고, 저역 럼블이 다가왔다 멀어진다
- 공정성: 도로 폭 6.4m ÷ 걷기 3.2m/s ≈ 2.1초 < 점멸 2.5초 —
  **초록에 출발하면 반드시 건넌다.** 점멸에 출발하는 것은 플레이어의 판단
- **튜토리얼(낮)에서도 치이면 접힌다** — 튜토리얼이 안전지대인 것은 괴담에 한해서다.
  단 낮에는 접힘 자각 문구와 분필 자국을 띄우지 않는다 (괴담 누출 방지)

## 3. 깊이 — 유일한 자원 (밤 한정)

- 깊이는 숫자로 표시되지 않는다. **가로등 밝기가 게이지다**: 깊이 0~5에서
  가로등 26→20→14→9→5.5→3 (앰비언트·안개 연동). 여기에 **비네트** —
  화면 가장자리가 저채도 적으로 조여들고, 깊이 4+에서 느린 맥동.
  **응시 중에도 같은 비네트가 조여든다** (붙잡히는 중이라는 즉각 피드백).
- **깊이 6 도달 = soft fail**: 암전 → "…여기가 어디지" → 가게 앞에서 그 밤을
  처음부터 (깊이·구간 수 리셋, 밤 유지). 접힘 3회 또는 빈 지적만 6회면 도달.
  퇴근길(튜토리얼)에는 깊이가 쌓이지 않는다.

## 4. 구현된 콘텐츠

**구간 테마 5종**: 원룸 골목 / 상가 골목 / 놀이터 옆길 / 정류장 앞 / 먹자골목 입구 —
프리팹 1개 + 테마 전환 방식, 구간당 도보 14초 내외 — 터널 포함
(무결점 귀갓길 **걸음 68.9초** + 차도 신호 대기 0~9초. 대기는 주기 안에서 매번 달라
합계로는 고정값이 아니다 — `verify:balance`가 둘을 나눠 찍는다).
**낮/밤 조명 전환**: 첫날 퇴근길은 밝은 하늘·태양광·옅은 안개·가로등 소등.
**개업 현수막**(테마 4 끝, **왼쪽 벽면에 밀착**): 튜토리얼 자막이 가리키는 실물.
밤에도 그대로 걸려 있지만 어둠에 먹혀 저채도로 보여 이상현상 신호색과 경쟁하지 않는다.
**다리 밑 터널** (v0.11.16 구조 / v0.11.21 마감): 개구부를 지나면 터널(9m·개구부 폭·천장 3.4m)로
들어가고 **한가운데의 암흑에서 다음 구간으로 넘어간다**. 화면 페이드가 아니라 안개·배경색·
조명을 함께 검정으로 몰아(density 1.4) 세계가 어두워진다. 앞뒤 터널이 대칭이라 들어간 만큼
나오므로 걸음이 끊기지 않는다. **뒤에는 언제나 지나온 터널** — 깊이 되돌아 들어가면
벽 대신 **골목이 돌려세운다** (v0.11.18: 걸음이 멈추고 0.9초 뒤 다시 골목 쪽을 보고 있다 —
"어느새 다시, 이쪽을 보고 있다". 암흑 속 막다른 끝에 갇히지 않는다),
마지막 구간에서는 터널 대신 목적지가 나온다.
터널의 콘크리트는 **골목 벽과 같은 것**(옹벽 = 왼쪽 벽, 갱구·다리 옆면 = 오른쪽 벽)이고,
형태는 갱구 액자 · 옹벽 신축이음 · 걸레받이 · 천장 보 4개 · 측구 · 천장 등기구 2개(광원은
가운데 하나) · 하늘에 걸리는 난간 기둥 열로 이루어진다. 통로 폭은 옹벽 안쪽면 ±1.5m,
플레이어 한계 ±1.25m — 카메라가 콘크리트에 들어가지 않는다.
**앞뒤 터널은 완전한 거울상**이고 차이는 마감벽 거리 하나뿐이다 (앞 4m = 더 이어지는 것처럼 /
뒤 0.6m = 막힌 끝). 골목 **양 끝에 끝벽**이 하나씩 있어 개구부 외에는 다 막힌다 —
뒤쪽에 없던 시절에는 돌아보면 터널 옆으로 바깥이 보였다 (v0.11.22).
구간 시작 위치는 z=−0.5 (뒤 갱구 바로 앞), 끝벽 통과 방지는 앞뒤 모두 0.5m.

**이상현상 9종** (전부 구현·가시성 검증 — 상세는 [anomalies.md](./anomalies.md)):

| 구간 | 이상현상 (effect) — 규칙 |
|---|---|
| 1 원룸 골목 | 바닥 핏자국(blood_trail, 직시) · 배출장 위 백골(skull, 직시, 밤 2) · 창문의 얼굴(face_window, **외면**, 밤 2) |
| 2 상가 골목 | 셔터의 손자국들(handprints, 직시) |
| 3 놀이터 옆길 | 그네에 앉은 형체(swing_figure, **외면**) · 펜스 뒤 어둠의 눈(eyes, **외면**, 밤 2) |
| 4 정류장 앞 | 정류장의 앉은 형체(bus_figure, **외면**) |
| 5 먹자골목 입구 | 끌린 자국(drag_mark, 직시) |
| 전 구간 (스폰 앵커) | 그림자 사람(figure, **외면**, 밤 2 — 앵커 6곳 중 랜덤) |

**연출·흐름**: 타이틀 단일 게이트 — 시작 버튼 문구는 상황에 따라 바뀐다
(첫 방문 "퇴근길에 나선다" / 이어하기 "가게를 나선다"). 첫 방문은 제목 · 전제 한 줄 · 시작 버튼 ·
⚙ 설정(밝기·소리·이어폰·조작 참조) · 개인정보처리방침 버튼뿐. 방문 도장 카드
("FF-1204 — 방문 도장", 밤 6+ 칸 밖 도장)와 이어하기는 **재방문에만** →
[첫 방문] 첫날 퇴근길 튜토리얼(2구간) → 가게 컷 → 밤 1 귀갓길 → 밤별 인트로 모놀로그 →
걷기/직시·외면 → 집 도착 → 귀가 연출(등급 + 밤별 에필로그, Peak-End) →
"또 갔다 왔다" 컷 → 다음 밤. **온보딩 힌트 3종**(각 1회, 상단, 자동 소멸): 걷기(6m 걸으면 해제) ·
직시(첫 흔적 12m 접근) · **외면**(첫 사람 형태 18m 접근 — 응시 판정 거리 11m보다 먼저).

**플랫폼·설정**: 이동 속도는 하나 — 전진 3.2m/s, 좌우 절반(1.6), 뒷걸음 0.65배(2.1).
PC(포인터락+WASD, 클릭=직시) / 모바일("걷는다" 버튼 홀드=전진,
화면 드래그=시점, 탭=직시 — 조이스틱·달리기 없음), 밝기·소리 설정,
기기 내 저장(localStorage — 밤·튜토리얼 완료·기록·설정, 서버 전송 없음), 뒤로가기=일시정지,
단일 파일 오프라인 빌드(play-local.html). 에셋 0 (프리미티브+캔버스 텍스처+프로시저럴 사운드).

## 5. 아직 없는 것 (로드맵 M3~M4)

- 밤 2~5의 고유 규칙(커뮤니티 앱·힌트·모순/거짓 힌트), **규칙형 괴담**(존재별 예외 규칙),
  **한국 도시전설 변형 존재 확충**, 밤별 세트피스, 엔딩 3종, 밤 5의 규칙 배신,
  접힘 변주 심화(프롭 변주), 사운드·조명 폴리시.
- 검증 잔여: 직접 처음부터 플레이(퇴근길 튜토리얼 포함 전체 흐름), 모바일 실기기 확인.

## 6. 검증 도구 (개발자용)

- `?a=<effect>` — 해당 구간에서 이상 고정 (`?a=none` = 항상 정상). **튜토리얼 생략** (E2E 결정성)
- `?t=1` — 첫날 퇴근길 튜토리얼 강제 재생 (스크린샷 검증용)
- `?avert=off` — 응시 붙잡힘 정지 (사람 형태를 정면에서 촬영하기 위한 검증 전용)
- `?anchor=0..5` — 그림자 사람의 스폰 앵커 고정 (기본 2)
- `window.__fries.occlusion()` — **가림 검사** (?a= 한정): 현재 구간의 이상현상이
  시선에서 가려지는지 메시 단위 레이캐스트로 판정 — 배치 3원칙 ②'관찰 시간 확보' 자동 검증
- `npm run verify:sim` — 깊이 모델 시뮬레이션 10건 (<1초, 브라우저 불요)
