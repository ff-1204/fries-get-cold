# 현재 빌드 명세 — 규칙·콘텐츠 현황

**v0.9.0 (2026-08-02) 기준.** 라이브 빌드에 실제로 들어 있는 것만 적는다 —
기획·로드맵은 [game.md](./game.md), 버전별 상세 이력은 CHANGELOG.md.
릴리즈마다 이 문서를 실빌드와 대조해 갱신한다.

## 1. 목표와 승리 조건

- **밤(일차)의 목표**: 집에서 출발해 골목 구간들을 지나 **새벽약국에 도착**하면 그 일차 완주.
  약(FF-1204) 하루치를 받고, 귀가는 컷으로 처리 → 복약 연출 → 다음 일차.
- **완주 등급** (복약 서사 — 접힘 횟수가 결정):

  | 접힘 | 복약 문구 | 기록 |
  |---|---|---|
  | 0회 | "늦지 않았다 … 통증이 가라앉는다" | crispy (노미스) |
  | 1~2회 | "조금 늦었다 … 약효가 도는 데 한참" | lukewarm |
  | 3회+ | "많이 늦었다 … 한동안 웅크리고" | soggy |

- **최종 엔딩은 아직 없다** — 일차는 무한히 이어지며(6일차부터 텍스트는 5일차 것을 반복,
  처방 카드에 칸 밖 체크가 늘어난다), 기획된 엔딩 3종(끊는다 / 삼킨다 / 히든 "완치" =
  전 일차 노미스)은 M3에서 5일차와 함께 구현 예정. 현재 빌드의 "승리"는 **일차 단위 완주**다.
- **패배(게임 오버)도 없다** — 놓침은 죽음이 아니라 연장(§2 접힘), 깊이 한계는
  같은 일차 재시작(§3 soft fail). 죽음·유혈 '묘사' 없음 — 흔적(핏자국)까지만 (design-principles §1).

## 2. 코어 규칙 — 직시와 접힘·증식

- 일차는 구간 5개로 시작한다 (HUD "1일차 — 1/5 — 원룸 골목"). 이동은 **직진뿐** — 갈림길 없음.
- 구간마다 **환각 0~복수 개**가 배정된다 (확률: 기본 0.4 + 경과 1분당 0.06, 상한 0.8.
  동시 개수 = 1 + 증식 단계. 1일차 첫 구간은 항상 정상, 1일차 후반까지 무환각이면 강제 등장).
  위치 자유형 환각(그림자 사람)은 구간의 스폰 앵커 6곳 중 랜덤 지점에 출현.
- **판정 = 직시**: 있어서는 안 되는 것에 **다가가서(4.5m 이내)** 똑바로 본다
  (PC: 크로스헤어에 놓고 클릭 / 모바일: 탭). 멀리서는 "…여기서는 확신이 안 선다"(비용 없음).
  **직시한 환각은 사라진다** — "원래, 없던 것이다" (v0.9.0 전환: 확인 잔존 → 직시 소멸).

  | 구간 상태 | 전부 직시하고 나감 | 직시 안 하고 나감 | 엉뚱한 것을 짚음 |
  |---|---|---|---|
  | 정상 | — | ✅ 통과 | ⚠ **깊이 +1** (빈 의심 — "머리가 지끈거린다") |
  | 환각 (1개 이상) | ✅ 통과 (무비용, 환각 소멸) | 🌀 **접힘 + 증식** | ⚠ 깊이 +1 (그 후 다시 짚을 수 있다) |

  연타는 쿨다운(0.6초)으로 차단.
- **접힘** = 홀림의 결과. 같은 테마 구간이 미묘하게 달라진 채 반복되고,
  총 구간 수가 +1 (카운터 "3/5" → "4/6"), 깊이 +2. 접힘 순간: 카운터 페이드 교체 +
  reveal 자막(무엇을 지나쳤는지) + 사운드 드랍 + 반복 구간 입구 바닥의 분필 원.
- **증식** = 지나칠 때마다 이후 구간의 동시 환각 수 +1 (1 → 2 → 3 상한).
  전부 직시해야 통과이므로, 지나칠수록 밤은 길고 어둡고 붐빈다.

## 3. 깊이 = 병세 — 유일한 자원

- 깊이는 숫자로 표시되지 않는다. **가로등 밝기가 게이지다**: 깊이 0~5에서
  가로등 26→20→14→9→5.5→3 (앰비언트·안개 연동). 여기에 **통증 비네트**(v0.9.0) —
  화면 가장자리가 저채도 적으로 조여들고, 깊이 4+에서 느린 맥동.
- **깊이 6 도달 = soft fail**: 암전 → "…쓰러졌던 모양이다" → 골목 입구에서 같은 일차를
  처음부터 (깊이·구간 수 리셋, 일차 유지). 접힘 3회 또는 빈 의심만 6회면 도달.

## 4. 구현된 콘텐츠

**구간 테마 5종** (구조 차별화 완료): 원룸 골목 / 상가 골목 / 놀이터 옆길 / 정류장 앞 /
먹자골목 입구 — 프리팹 1개 + 테마 전환 방식, 구간당 도보 40초 내외 (무결점 편도 43.5초).

**환각 9종** (전부 구현·가시성 검증 — 상세는 [anomalies.md](./anomalies.md).
v0.9.0: 구 일상 어긋남 14종은 풀에서 퇴역, 코드 핸들러만 잔존):

| 구간 | 환각 (effect) |
|---|---|
| 1 원룸 골목 | 바닥 핏자국(blood_trail) · 배출장 위 백골(skull, 2일차) · 창문의 얼굴(face_window, 2일차) |
| 2 상가 골목 | 셔터의 손자국들(handprints) |
| 3 놀이터 옆길 | 그네에 앉은 형체(swing_figure) · 펜스 뒤 어둠의 눈(eyes, 2일차) |
| 4 정류장 앞 | 정류장의 앉은 형체(bus_figure) |
| 5 먹자골목 입구 | 끌린 자국(drag_mark) |
| 전 구간 (스폰 앵커) | 그림자 사람(figure, 2일차 — 앵커 6곳 중 랜덤 출현) |

**연출·흐름** (v0.9.0 — 프롤로그 시퀀스 제거): 타이틀 단일 게이트(01:04 시계 · 처방 카드
"FF-1204 — 5일분" = 디제틱 진행 표시, 6일차+는 칸 밖 체크) → 일차 시작 모놀로그(5종,
통증→환각→벗어남 아치) → 걷기/직시 → 새벽약국(복약 체크 +1) → 귀가 컷 →
복약(물 한 모금 ×2 + 일차별 에필로그 5종, Peak-End) → 다음 일차.

**플랫폼·설정**: PC(포인터락+WASD+Shift 달리기, 클릭=직시) / 모바일("걷는다" 버튼 홀드=전진·
위로 밀면 달리기, 화면 드래그=시점, 탭=직시 — 조이스틱 없음), 밝기·소리 설정,
기기 내 저장(localStorage — 일차·기록·설정, 서버 전송 없음), 뒤로가기=일시정지,
단일 파일 오프라인 빌드(play-local.html). 에셋 0 (프리미티브+캔버스 텍스처+프로시저럴 사운드).

## 5. 아직 없는 것 (로드맵 M3~M4)

- 2~5일차의 고유 규칙(커뮤니티 앱·힌트·모순/거짓 힌트), 일차별 세트피스 5종
  (4일차 "골목의 호의", 5일차 귀갓길 반전 포함), 엔딩 3종, 환각 확장(깊이 해금·개인화 환각),
  접힘 변주 심화(프롭 변주), 사운드·조명 폴리시.
- 검증 잔여: 직접 처음부터 플레이(무설명 학습 확인), 모바일 실기기 확인.

## 6. 검증 도구 (개발자용)

- `?a=<effect>` — 해당 구간에서 환각 고정 (`?a=none` = 항상 정상)
- `npm run verify:sim` — 깊이 모델 시뮬레이션 10건 (<1초, 브라우저 불요)
- `npm run verify:balance` — E2E 실측 4케이스 (무결점 일차 / 접힘 3회→입구 리셋 / 직시 통과 / 빈 의심)
- `npm run verify:shots` — 환각 정상/이상 쌍 + 테마 + 접힘 시각 요소 스크린샷
