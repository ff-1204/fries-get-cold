# 게임 디자인 이론 — 프로젝트 적용판

이 게임의 설계 결정을 뒷받침하는 게임 디자인 이론과, 각 이론의 우리식 적용 규칙.
새 시스템을 설계할 때 이 문서로 "왜 이렇게 만드는가"를 검증한다.

> 상위 원칙: [design-principles.md](./design-principles.md) §0(어포던스·정직한 판정)이 우선한다.
> 공포 쪽 이론적 근거는 [fear-cognition.md](./fear-cognition.md), 감정·색·페이싱은 [affective-design.md](./affective-design.md).

---

## 1. MDA 프레임워크 — 설계와 경험은 반대 방향으로 흐른다

Mechanics(규칙) → Dynamics(플레이 중 발생하는 행동) → Aesthetics(플레이어가 느끼는 재미).
설계자는 M을 만들지만 플레이어는 A부터 경험한다 — 그래서 **A(목표 경험)를 먼저 정의하고 M을 역산**한다.

| 층위 | 이 게임 |
|---|---|
| Aesthetics (목표 경험) | 서스펜스(의심의 재미) + 도전(관찰 유능감) + 서사(담담한 유머의 밤) |
| Dynamics (기대 행동) | 골목을 훑어보는 시선, 짚을까 말까의 망설임, 카운터가 늘어나는 순간의 서늘함, "한 밤만 더" |
| Mechanics (규칙) | 이상현상 확률, 지적 판정(직접 짚기), 접힘(놓침=연장), 깊이(가로등 소등·이상 심화), 힌트 시스템 |

**적용 규칙**: 새 메커니즘 제안 시 "이게 어떤 Dynamics를 낳고, 그게 목표 Aesthetics에
기여하는가"를 역방향으로 검증한다. 예: 인벤토리 시스템은 Dynamics(아이템 관리)를 낳지만
목표 Aesthetics(의심·관찰)에 기여하지 않음 → 기각.

## 2. 의미 있는 선택 (Interesting Decisions)

"게임은 흥미로운 결정의 연속"(시드 마이어). 결정이 흥미로우려면 세 조건이 필요하다:
**불완전한 정보 + 실질적 득실 + 자동 최적해 부재.**

지적("짚을까, 지나칠까") 선택의 성립 조건 점검:

- 불완전한 정보 ✓ — 이상 유무는 관찰로 추정할 뿐 확정 불가 (거짓 힌트는 단서 동반)
- 실질적 득실 ✓ — 접힘(놓침) 리스크 vs 빈 지적 비용의 비대칭
- 자동 최적해 부재 ✓ — "다 짚어보기" 전략은 깊이 누적(가로등 소등·입구 리셋) + 쿨다운으로 차단

**적용 규칙**: 밸런싱 변경 시 이 세 조건이 유지되는지 확인한다. 특히 빈 지적 비용이 너무
낮아지면 선택이 죽는다 — "일단 다 짚는 게 이득인가?"를 플레이테스트 질문에 상시 포함.

## 3. 몰입(Flow) — 도전과 실력의 균형

너무 쉬우면 지루, 너무 어려우면 불안. 실력이 느는 속도에 맞춰 도전을 올린다.

**적용 규칙**:

- 밤 1~5 = 난이도 곡선 (이상 1종·명확 → 다종·사람 형태 → 모순 힌트 → 거짓 힌트).
- 실력의 정체는 "관찰력과 기억력" — 새 밤은 새 조작이 아니라 **새 관찰 과제**를 준다.
- 실패는 밤 단위 재시작(짧은 루프)이라 좌절 대신 "아까 그거였구나"의 학습으로 이어진다.
- 플레이테스트 지표: 밤별 실패 횟수가 1~3회면 적정, 0회면 쉬움, 5회+면 공정성 점검.

## 4. 플레이어 에이전시 — 호러의 역설을 우리식으로 풀기

호러는 전통적으로 에이전시를 빼앗아(느린 이동, 무력한 주인공) 공포를 만들지만,
과도한 무력감은 좌절과 불공정으로 이어진다 (장르 연구의 공통 지적).

**우리의 해법 — "정보 에이전시"**: 신체 능력은 평범하게 유지하되(달릴 수 있음, 막히지 않음),
**아는 만큼 안전해지는** 구조로 긴장을 만든다. 플레이어는 무력해서 무서운 게 아니라
"내 판단이 맞나?"라서 무섭다. 이것은 15세 기준([design-principles.md](./design-principles.md) §1-1)과도
맞물린다 — 대처 수단이 항상 존재하는 공포는 감당 가능한 공포다.

**적용 규칙**: 에이전시를 빼앗는 연출(강제 걷기, 조작 잠금)은 프롤로그·엔딩 외 금지.
긴장은 항상 "정보의 불확실성"에서 만든다.

## 5. 자원 경제 — 하나의 자원, 두 개의 지출구

**깊이**가 유일한 자원이다 (정확히는 "여유"의 소진). 오답(접힘)은 크게, 과잉 경계는
작게 같은 자원을 소모한다 — 신중함도 대담함도 결국 같은 통화를 쓰므로 단일 축이라
이해가 쉽고 딜레마는 깊다. 잔량 표시는 숫자가 아니라 **남은 가로등 불빛**(다이제틱).

**적용 규칙**: 새 자원(배터리, 스태미나 등) 추가 금지. 자원이 늘면 인지 부하가 늘고
([affective-design.md](./affective-design.md) §1-5 힉의 법칙) 핵심 딜레마가 희석된다.
확장은 자원 추가가 아니라 **기존 자원에 대한 새로운 압박**(깊이가 저절로 차는 밤,
줄어드는 남은 거리 등)으로 한다.

## 6. 온보딩 — 가르치지 말고 겪게 하라

규칙 설명 없이 레벨 디자인으로 가르치는 계층적 학습(밸브식 온보딩):

1. 밤 1 첫 구간은 **이상 없음 보장** — 그냥 걷는 기준 경험(정상 상태의 학습)
2. 첫 이상현상은 **큼직하고 짚기 쉬운 것** — 크로스헤어 + 조작 안내 한 줄이 짚기를 잇는다
3. **첫 접힘은 저작 이벤트로 보장** (밤 1) — 오답 직후 reveal 암시 + 카운터 +1을
   낮은 긴장에서 겪게 해 "오답 = 죽음이 아니라 연장"의 문법을 완성 (§9 스키마 위반 1)

**적용 규칙**: 텍스트 튜토리얼이 필요해 보이면 레벨 배치를 고친다 (design-principles §0
발견 가능성). 시작 화면의 조작 안내 한 줄만 예외.

## 7. 숙련 목표와 리플레이 — "한 밤만 더"의 설계

- 단기 루프: 구간(1~2분) → 중기: 밤(10~15분) → 장기: 다섯 밤 + 히든 엔딩(노미스).
- 히든 엔딩은 외적 보상(포인트·배지)이 아니라 **숙련의 증명 + 서사 보상** — 내재적 동기.
- 접힘·깊은 밤은 실패가 아니라 "더 잘 볼 수 있었다"의 신호 — 재도전의 심리적 낙차를
  작게 유지한다 (도전 욕구는 남기고 좌절은 남기지 않기).

**적용 규칙**: 일일 보상, 수집 요소 늘리기, 타이머 기반 유인 등 외적 장치 금지
(design-principles §0 게이미피케이션 가드레일).

## 8. 스코프 이론 — 소품의 완성도가 대작의 야심을 이긴다

장르 시장 조사([trend-research.md](./trend-research.md))의 결론을 설계 원칙으로 승격:
1~2시간 볼륨 + 낮은 가격 + 높은 밀도가 이 장르의 승리 공식. 콘텐츠 추가 요청이 생기면
"밤 6을 만들 것인가, 밤 1~5를 더 다듬을 것인가"에서 항상 후자를 택한다.

## 9. 장르 스키마와 심적 모델 — "접히는 골목"의 학습성 (2026-08-02 컨셉 검토)

플레이어는 백지가 아니라 **장르 스키마**(그 장르 게임들에서 학습한 기대의 다발)를 들고
온다. 새 컨셉이 사용자에게 익숙한지는 "스키마와 일치하는 토대 위에, 위반 지점을
가르칠 수 있는가"로 판정한다.

**익숙한 토대 (스키마 일치 — 학습 비용 ≈ 0):**

- 이상현상 관찰 문법은 이미 대중화된 장르 스키마다 — "같은 공간 반복 + 어긋남 찾기 +
  판정"은 설명 없이 통한다 ([trend-research.md](./trend-research.md) 시장 근거)
- "걸어도 걸어도 끝나지 않는 길"은 보편적 악몽 문법 — 시스템 이전에 직관으로 공명한다
- 반복 공간의 미세 변주는 조명·소품 변화만으로도 강한 심리 효과 — 신규 에셋 없이
  성립하는 저비용 고효율 문법 ([fear-cognition.md](./fear-cognition.md) §1 예측 오류)

**스키마 위반 지점 (여기서 이해가 갈린다 — 학습 설계 필수):**

1. **오답 = 죽음이 아니라 연장** — 장르 기대(오답=실패·즉사)와 다르다. 첫 접힘이
   "버그"나 "페널티 없음"으로 오해되면 컨셉 전체가 무너진다 → 접힘 인지 보장 4요소
   ([game.md](./game.md) 판정 절) + 첫 접힘은 저작 이벤트 (§6 온보딩 3단계)
2. **깊이 = 숨은 자원** — 숫자 없는 자원은 불공정 위험 → **가로등 = 다이제틱 깊이
   게이지** (남은 불 수 = 남은 여유). §4 정보 에이전시·design-principles §0 정직한 판정과 연결
3. **과잉 의심의 비용** — 빈 지적의 비용(깊이 +1)이 체감되지 않으면 §2의 선택 조건이
   죽는다 → 짚은 그 순간 가로등이 어두워지는 **즉각 인과 연출** + 연타 쿨다운

**동기 이론 점검:**

- **목표 구배 효과** (Hull 1932; Kivetz 외 2006): 목표에 가까울수록 동기·속도가 오른다 —
  버거집 불빛이 커지는 연출이 양(+)의 구배. 접힘(카운터 증가)은 구배의 역행이라
  강력한 좌절 장치다 — 남발 금지, 깊이 한계(입구 리셋)로 하방을 보장한다
- **손실 회피** (Kahneman & Tversky 1979): 접힘은 "거리의 손실" — 즉사보다 부드럽지만
  손실이라 충분히 아프다. 오답이 관전자에게도 "끝"이 아니라 "더 깊어짐"인 구조는
  장르 표준(즉사·리셋) 대비 라이트 유저·스트리밍 관전 접근성이 좋은 차별점이다
- **학습된 무기력 방지** (Seligman 1972): 인과를 모르는 반복 처벌은 무기력을 낳는다 —
  접힘마다 reveal(무엇이 어긋났었는지 암시)은 공정성이 아니라 **동기 유지 장치**이기도
  하다. soft fail(입구 리셋)은 처벌이 아니라 "알고 다시 시작"의 자비로 연출한다

**적용 규칙**: 장르 스키마에서 벗어나는 규칙은 **첫 발생을 저작 이벤트로 보장**한다
(무작위에 맡기지 않는다). 스키마와 일치하는 규칙은 설명은커녕 연출도 아끼고, 위반
지점에만 학습 예산을 집중한다.

## 체크리스트 (새 시스템 설계 시)

- [ ] 목표 Aesthetics(서스펜스·유능감·유머)에 기여하는가 (MDA 역방향 검증)
- [ ] 선택의 세 조건(불완전 정보·실질 득실·자동해 부재)을 해치지 않는가
- [ ] 난이도 곡선의 제자리에 있는가 (밤 몇에 넣을 것인가)
- [ ] 에이전시를 빼앗지 않고 정보 불확실성으로 긴장을 만드는가
- [ ] 새 자원을 추가하지 않는가
- [ ] 텍스트 설명 없이 학습 가능한가
- [ ] 장르 스키마에서 벗어나는 규칙이라면 첫 발생이 저작 이벤트로 보장되는가 (§9)
- [ ] 스코프를 넓히는가, 밀도를 높이는가 (후자만 통과)
