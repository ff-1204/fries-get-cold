# 개인정보처리방침 (Privacy Policy)

시행일: 2026-08-02 (최초 시행 2026-07-29 — 변경 이력은 문서 하단)

「튀김이 식기 전에 (Before the Fries Get Cold)」(https://ff-1204.github.io/fries-get-cold/,
이하 "게임")는 이용자의 개인정보를 소중히 여깁니다. 이 문서는 게임이 어떤 정보를
다루는지(그리고 다루지 않는지) 있는 그대로 설명합니다.

## 1. 수집하는 개인정보 — 없습니다

게임은 **개인정보를 수집하지 않습니다.**

- 회원가입·로그인이 없습니다.
- 이름·이메일·전화번호 등 어떤 개인정보도 입력받아 서버로 전송하지 않습니다.
- 자체 분석 도구·추적 쿠키를 사용하지 않습니다.
- 게임 플레이 기록(진행 상황, 성공/실패)을 서버로 보내지 않습니다.

## 2. 기기 안에만 저장되는 정보 (localStorage)

이어하기 등 이용 편의를 위해 아래 기록을 **이용자의 브라우저 안에만** 저장합니다
(저장 키: `fries.save.v1`). 이 정보는 서버로 전송되지 않고, 게임 운영자를 포함해
누구도 열람할 수 없습니다.

| 항목 | 내용 |
|---|---|
| 진행 상황 | 다음에 시작할 밤, 첫날 아침(튜토리얼) 완료 여부 |
| 실패 기록 | 누적 실패 횟수 (히든 엔딩 판정용) |
| 시식 기록 | 밤별 결과 (바삭/미지근/눅눅) |
| 설정 | 화면 밝기, 소리 켬/끔 |

저장되는 것은 위 표가 전부이며, 이름·기기 정보 등 이용자를 식별할 수 있는 값은
어떤 형태로도 저장하지 않습니다.

## 3. 삭제 방법

- **게임 안에서**: 시작 화면의 **"기록 삭제 · 처음부터"** 버튼 (진행 기록이 있을 때 표시)
- **브라우저에서**: 브라우저 설정에서 이 사이트의 **사이트 데이터(로컬 저장소)** 삭제

삭제해도 이용에는 제한이 없으며, 1일차 첫 상태로 되돌아갈 뿐입니다.

## 4. 호스팅 과정의 접속 기록

게임은 GitHub Pages에서 호스팅됩니다. 웹사이트 접속이라는 기술적 특성상, 호스팅 제공자인
GitHub이 서비스 제공·보안을 위해 접속 IP 주소 등을 일시적으로 처리할 수 있습니다. 이는 게임
운영자가 수집하거나 열람하는 정보가 아닙니다. 자세한 내용은
[GitHub 개인정보 보호정책](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)을
참고하세요.

게임은 추후 유료 확장판(스팀 등) 출시나 광고 게재를 검토할 수 있습니다
([commercial.md](./commercial.md)). 광고 등 제3자 데이터 처리가 도입되면 **시행 전에**
이 방침을 갱신하고 상단의 시행일을 새로 표기합니다. **현재는 광고와 관련 쿠키가 없습니다.**

## 6. 아동의 개인정보

게임은 연령과 무관하게 어떤 개인정보도 수집하지 않으므로, 만 14세 미만 아동의
개인정보 역시 수집하지 않습니다.

기기 내 저장 데이터는 위 3항의 방법으로 이용자가 직접 삭제할 수 있습니다.

## Privacy Policy — English Summary

Effective date: 2026-08-02 (first effective 2026-07-29). "Before the Fries Get Cold"
collects **no personal data**:
no accounts, no sign-ups, no analytics, no tracking cookies. Game progress (current night,
fail count, per-night results) and settings (brightness, sound on/off) are stored only in your browser's
localStorage (key `fries.save.v1`) and are never transmitted; delete them anytime with the
in-game "기록 삭제 (Delete records)" button or by clearing this site's data in your browser.
The game is hosted on GitHub Pages, which may technically process connection data such as IP
addresses to serve the site (see GitHub's privacy statement). If ads or paid editions are
introduced in the future, this policy will be updated before they take effect.
Questions: [dorimhan@kakao.com](mailto:dorimhan@kakao.com).
