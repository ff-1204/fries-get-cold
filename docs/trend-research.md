# 조사 기록

기획 근거가 된 장르·시장 조사. 새 조사는 출처와 함께 이 문서에 추가한다.
(조사일: 2026-07 하순 / 장르 단위로 기록한다)

## 장르 조사 — 루프형 이상현상 관찰 호러

- 반복되는 일상 공간을 걸으며 "이상현상이 있으면 되돌아가고, 없으면 전진"하는
  판정 문법이 하나의 장르로 확립되어 있음 (스팀에 전용 큐레이터가 있을 정도).
- 장르의 강점: 규칙이 한 줄이라 튜토리얼 불요 / "저거 이상한 거 맞아?"라는 의심
  자체가 공포이자 재미 / 시청자가 같이 틀린그림찾기를 하게 되어 방송 친화적 /
  맵 재활용 구조라 1인 개발 스코프에 적합.
- **시장의 명확한 교훈: 무대만 바꾼 클론은 실패하고, 관찰 '방식' 자체를 비튼 작품만
  생존한다.** 장르 개척작조차 후속작에서 문법을 변형했다.
- 가격대 표준 2,300~5,600원, 볼륨 1~2시간 소품.
- 플레이어 평가 축 (리뷰 분석): 이상현상 명확성 > 깜놀 의존도 > 템포/볼륨 > 시각 요소.
  → [design-principles.md](./design-principles.md)에 반영.
- 한국 커뮤니티는 국산 시도에 우호적 ("국산이니 후원하자" 정서 관찰됨).
- **우리의 비틀기** = 직진 + 지적 판정(이상한 것을 직접 짚기) + 접히는 골목(놓침 = 죽음이
  아니라 연장·증식) + 깊이(꺼져가는 가로등) + 하찮음의 유머 — 무대 교체가 아니라 관찰의
  동사와 실패의 결과라는 문법 자체를 새로 설계. (초기안 본길/샛길·왕복·온도 타이머는
  2026-08-02 컨셉 전환으로 대체 — game.md 결정 기록)

## 장르 조사 — '일상 속 규칙 괴담' 정서

- 완벽해 보이는 일상 밑에 규칙 기반 괴담이 깔려 있고, 규칙을 파악한 자만 생존한다는
  서사 문법이 웹소설·게임·인터넷 괴담 등 여러 매체에서 널리 쓰이는 공용 장르 관습임.
- 채택한 관습: 일상적 의무감 × 괴담의 대비, 담담한 화자, 에피소드형 규칙,
  설명 없는 단서 기반 정보 전달.
- ⚠ 원칙: 장르 관습(공공 아이디어)만 쓴다. 특정 작품의 고유 설정·조직명·괴담·캐릭터·
  문구는 사용하지 않는다 → [commercial.md](./commercial.md) IP 리스크 관리.

## 시장 조사 — 인디 트렌드 (2025~2026)

- 심리 호러·편집증 테마 강세. "불신/의심" 코드가 장르 전반의 흐름.
- 바이럴 공식: "클립 한 개로 설명되는 콘셉트 + 플레이 중 저절로 생기는 공유 장면 +
  충동구매 가격" (소규모 단기 개발작이 초대형 흥행한 사례 다수).
- 개발 방식 트렌드: 거대 엔진 탈피(경량 프레임워크), 직접 유통, 데브로그 커뮤니티 빌딩.
- 우리 게임의 클립 한 줄: "새벽에 감자튀김 사러 나갔는데, 골목이 끝나지 않음" — 통과.
- 출처: https://nosmallgames.com/2026/01/10-indie-game-trends-from-2025/ ·
  https://relishgames.com/journal/top-game-development-trends-of-2026/

## 기술 조사 — 브라우저 3D 게임

- Three.js + 정적 호스팅만으로 상업 품질 브라우저 3D 게임이 성립함을 확인
  (로우폴리 + 조명 연출, 수 MB 초기 로드로 즉시 플레이).
- 채택 기법: Draco 메시 압축, KTX2/Basis 텍스처 압축, three-mesh-bvh 충돌,
  초기 최소 로드 + 플레이 중 스트리밍, 텍스처 대신 셰이더로 용량 절약.
