# 게임 기획 총괄

「튀김이 식기 전에」의 컨셉·시스템·현재 상태·로드맵을 정리한 문서.
게임이 발전하면 이 문서에 계속 기록한다. (상세 서사는 [story.md](./story.md))

## 컨셉

- **로그라인**: 새벽 한 시, 감자튀김이 먹고 싶어진 자취생이 매일 밤 규칙이 바뀌는
  골목길을 지나 24시 버거집에 다녀오는 이야기.
- **정체성 삼각형**: 구조는 루프형 이상현상 관찰 문법에서, 정서는 '일상 속 규칙 괴담' 장르에서,
  차별점은 우리 것에서(왕복 + 온도 타이머 + 하찮음의 유머).
- **한 줄 요약**: "골목이 아무리 이상해도, 감자튀김은 먹어야 하니까."
- 톤: 담담한 체념. 주인공은 비명 대신 "아." — 무서워서 침착한 게 아니라 내일 출근해야 해서 침착하다.
- **타깃 등급: 15세 이용가** — 유혈·잔혹 표현 없이 심리적 공포만 ([design-principles.md](./design-principles.md) §1-1)

## 코어 루프

```
[집] → 구간1 → 구간2 → 구간3 → 구간4 → 구간5 → [버거집]
        (구간을 관찰하며 걷고, 구간 끝 갈림길에서 본길/샛길 선택)
[버거집] → (감자튀김 구매, 온도 게이지 시작) → 역순 귀가 → [집] → 시식 연출
```

### 판정 — 본길/샛길 우회 시스템
- 구간마다 이상현상 유/무가 랜덤 배정된다 (데이터 테이블 기반, [anomalies.md](./anomalies.md))
- 구간 끝에 갈림길: **정상 → 본길(빠름)** / **어긋남 → 샛길로 우회(느림)**
- 어긋난 구간의 본길 진입 = **그 밤 실패** (침대에서 눈뜸). 과잉 경계(정상인데 샛길) =
  실패가 아니라 **시간·온도 손해** — 실패 리스크와 비용 리스크의 비대칭이 이 시스템의 핵심
- **새벽이 깊어질수록 이상현상 등장 확률 상승** — 우회 남발(안전 플레이)에 대한 자연 압박
- 힌트 소스: 전단지, 안내문, 커뮤니티 앱(스마트폰 UI), 버거집 알바의 한 마디

### 가는 길 — 관찰 모드
- 온도 압박 없음. 신중하게 관찰하고 규칙을 학습하는 구간 (단, 시간 = 위험 증가)

### 오는 길 — 온도 모드
- 온도 게이지가 실시간 감소. 도착 시 잔량에 따라 시식 연출 차등 (바삭/미지근/눅눅)
- 관찰 여유 없음: 가는 길에 본 구간 상태를 **기억**에 의존해 본길/샛길을 즉시 선택
- 우회할 때마다 온도 하락 — "안전하게 눅눅" vs "빠르게 위험" 딜레마
- 뛰면 빠르지만 소음 발생 → 특정 규칙과 충돌할 수 있음 (밤 3 "뛰지 마세요" 등)
- 온도 게이지 자체가 공포 장치: 식지 않는 밤, 너무 빨리 식는 밤, **올라가는 밤**

## 구조 — 다섯 밤

| 밤 | 테마 | 시스템 도입 | 서사 비트 |
|---|---|---|---|
| 1 | 그냥 좀 이상한 동네 | 이상현상 1종, 큼직한 것만 | 성공 경험. "세탁소가 왜 열려 있지" |
| 2 | 규칙이 있다는 걸 아는 밤 | 명시적 규칙 힌트, 커뮤니티 앱 | 힌트를 남기는 이웃들의 존재 |
| 3 | 아는 얼굴이 생기는 밤 | 사람 형태 이상현상, 귀갓길 규칙 | 알바의 경고 "뛰지 마세요, 오늘은요" |
| 4 | 규칙이 충돌하는 밤 | 모순 힌트(작성 시간으로 판별), 온도 이상 | 내일 날짜의 영수증 |
| 5 | 먹고 싶지 않은 밤 | 거짓 힌트(필체 차이), 규칙 배신 | 불 꺼진 버거집, 선택 → 엔딩 분기 |

## 엔딩

- **A 바삭**: 봉투를 두고 나온다 → 냉동 감자튀김 → "오늘은 이게 맞는 것 같다"
- **B 눅눅**: 봉투를 가져온다 → 완벽한 맛 → 밤 1로 루프 (2회차 명분, 디테일 미세 변화)
- **히든 "포장 주문"**: 5밤 노미스 → 알바의 미소 → "포장 주문은 골목에다가요" → 밝은 새벽 스태프롤

## 스코프 원칙

- 플레이 타임 1~2시간, 소품 볼륨. 늘리지 말고 다듬는다 (장르 시장의 교훈)
- 맵은 골목 구간 5개 재활용. 콘텐츠 확장은 코드가 아니라 데이터(JSON)로
- 한 구간 도보 1~2분 이내 — 리셋의 고통 최소화
- 몬스터 AI·추격전·오픈월드 없음. 공포는 전부 "어긋남의 인지"
