# 게임 기획 총괄

「튀김이 식기 전에」가 **무엇을 만드는 게임인가**. 허브 문서다.
지금 빌드에 든 것은 [spec.md](./spec.md), 서사는 [story.md](./story.md),
밤별 현황은 [stages.md](./stages.md), 버전별 경위는 CHANGELOG.md.

---

## 컨셉

**로그라인** — 동네에 감자튀김집 FF-1204가 새로 생겼다. 개업 현수막: XXXXL 감자튀김.
퇴근길에 현수막을 보고 들른 길은 평범했고 튀김은 맛있었다.
문제는 나와 보니 **밤**이라는 것. 그리고 돌아가는 길에, 있어서는 안 되는 것들이 서 있다.
**목적은 하나 — 그것들을 피해서 집에 도착하는 것.**

**한 줄 요약** — "갈 때의 그 길이, 돌아올 때는 아니다."

**톤** — 담담한 체념 + 하찮음의 유머 (튀김·도장·그냥 집). 주인공은 비명 대신 "아."
무서워서 침착한 게 아니라, 내일 출근해야 해서 침착하다.

**3막 아치** — 초반 낯섦(밤 1–2 "그냥 무섭구나") → 중반 홀림·어긋남의 개인화
(밤 3–4 "상황이 나를 향한다") → 후반 목적 전도(밤 5 — 튀김이 아니라 **집에 돌아가는 것**).

**표현 수위: 법적 준수만.** 유혈 배제·암전 실패·점프스케어 총량제는 등급 제약이 아니라
심리 호러 정체성으로 유지한다 ([design-principles.md](./design-principles.md) §1).

### 정체성 — 이 게임만의 것

1. **직시/외면 2축** — 흔적은 봐야 사라지고, 사람 형태는 보면 붙잡힌다.
   시선 자체가 조작이자 위험이다. **"저건 흔적인가, 사람인가"의 판단이 실력이다**
2. **늘어나는 골목** — 놓침은 죽음이 아니라 **길어지는 남은 거리**.
   긴장의 축이 공포사(死)가 아니라 **귀가 불능(끝나지 않음)**이다
3. **귀갓길 구조** — 가는 길은 컷. 목적은 언제나 집에 도착하는 것
4. **퇴근길 튜토리얼** — 밝은 두 구간에서 정상 상태를 학습한다. 밤은 그 대비로 온다
5. **깊이** — 꺼져가는 가로등이 게이지다. 숫자를 보여주지 않는다

## 코어 루프

```
[첫날 퇴근길 — 튜토리얼 2구간]
[정류장 4/5] → [먹자골목 입구 5/5] → [FF-1204]   위협 없음 · 약 21초
        ↓ 먹고 나오니 밤이다
[밤 N — 본게임]
[FF-1204] → 구간5 → 구간4 → 구간3 → 구간2 → 구간1 → [집]   테마 역순
        ↓ 귀가 연출(등급 = 늘어남 횟수) → 다음 밤은 "또 갔다 왔다" 컷에서 시작
```

판정 수치·연출의 현행 값은 전부 [spec.md](./spec.md)에 있다. 여기서는 **왜 그런가**만 적는다.

- **비대칭이 핵심이다.** 흔적은 봐야 하고 사람은 보면 안 된다 — 대응이 정반대라서
  "무엇인지 알아보는 것"이 게임의 동사가 된다
- **흔적의 직시는 멀리서 성립하지 않는다.** 무서운 쪽으로 **걸어가는 것**이 공포 코어다
- **사람 형태는 확인 의무가 없다.** 지나치는 것이 정답이므로 늘어남 대상이 아니다.
  대신 시선이 곧 위험이다
- **신호등은 이 게임 최초의 자원이다.** 기다리는 동안 서 있어야 하고,
  서 있는 동안 사람 형체에 취약해진다 — 통행과 관찰이 처음으로 충돌하는 지점
- **늘어남 인지 보장 4요소** — 놓침=연장은 장르 기대와 달라 오해 여지가 있다.
  ① 카운터 +1의 명시적 연출 ② reveal 암시 ③ **소리** — 사운드 드랍 + 가라앉는 저역
  (놀래키지 않는다. 총량제와 충돌하지 않는 유일한 방식이다) ④ 반복 구간의 분필 자국.
  빈 지적 비용도 즉각 인과로: 짚은 그 순간 가로등이 어두워진다
- **위험 표시는 시각에만 두지 않는다.** 외면 규칙의 정답이 *눈을 돌리는 것*이라
  화면으로만 알리면 **규칙을 지키는 순간 정보가 끊긴다.** 심박이 그 자리를 맡는다

### 힌트 소스

전단지, 안내문, 커뮤니티 앱(스마트폰 UI), 사장님의 한 마디.
기본 규칙 두 가지는 **첫 조우 1회의 조작 힌트**가 알려주고,
밤 2부터는 존재별 예외 규칙을 디제틱 힌트가 담당한다 (M3).

### 세트피스 — 밤마다 하나

절차적 이상현상과 별개로 밤마다 **저작된 세트피스 1개**를 배치한다.
아늑함→섬뜩함 커브를 밤 단위로 설계하는 장치이며, 무설명 학습 원칙은 그대로 —
세트피스도 텍스트 설명 없이 공간과 연출로만 말한다. (M3)

|---|---|---|---|---|
| 1 | 낯섦 | 퇴근길에 본 현수막 | **퇴근길 튜토리얼 2구간** → **밤 귀갓길 = 본게임**. 존재 1종씩만, 첫 늘어남의 안전한 학습 | 튀김은 진짜 맛있다(미끼). "새 가게가 왜 24시간을 하지" |

| 3 | 홀림 | 골목이 나를 아는 밤 | 사람 형태 비중 상승, 규칙형 괴담 도입(멈추면 안 되는 밤·인사하면 안 되는 것) | 어긋남의 개인화. 안 간 날짜에 찍힌 도장 |

## 엔딩 (M3)

- **A 두고 나온다** (정식) — 봉투도 완성된 쿠폰도 두고 나온다 → 집 앞 편의점 냉동 감자튀김 →
  "오늘은 이게 맞는 것 같다"
- **B 가져온다** — 봉투를 가져온다 → 돌아오는 길이 이상할 만큼 **짧다**.
  세 구간 만에 집이 나온다(골목의 호의) → 완벽한 맛 → 새 도장 카드와 함께 밤 1로 루프.
  ※ 도장은 '무료 보상'이 아니라 '방문 기록'이므로 가져올 명분은 재설계가 필요하다
- **히든 "단골"** — 5밤 노미스(늘어남 0) → 사장의 미소 → "포장 주문은 골목에다가요" →
  밝은 골목 스태프롤 (첫날 퇴근길과 같은 빛 — 수미상관)

## 스코프 원칙

- 플레이 타임 1~2시간, 소품 볼륨. **늘리지 말고 다듬는다**
- 맵은 골목 구간 5개 재활용 — 늘어남 반복도 같은 프리팹의 변주로. **신규 씬 없음**
- 콘텐츠 확장은 코드가 아니라 **데이터(JSON)**로
- 몬스터 AI·추격전·오픈월드 없음. 공포는 전부 **"어긋남의 인지"**
- 에셋 0 — 프리미티브 + 캔버스 텍스처 + 프로시저럴 사운드

## 확정된 판단 (바꾸려면 근거가 필요하다)

경위와 대안은 CHANGELOG.md에 있다. 여기 있는 것은 **지금 유효한 결론**뿐이다.

- **게임은 언제나 귀갓길이다.** 가는 길은 컷, 튀김은 밖에 나온 명분
- **판정은 2축이다** — `rule` 필드가 최종 결정한다 (관례는 OBJ=gaze / HUM=avert지만
  밤 5의 규칙 배신은 이 필드로 표현한다)
- **실패는 죽음이 아니다** — 늘어남(연장)과 soft fail(같은 밤 재시작)뿐
- **무설명 학습** — 규칙을 텍스트로 설명하지 않는다. 온보딩 보장 + 실패 reveal이 담당
- **콘텐츠는 데이터, 로직은 시스템** — 콘텐츠 추가에 코드 수정이 필요하면 설계 실패
- **표현 수위는 법적 준수만** — 올리는 결정을 할 때는 design-principles §1-1의 절차부터
- **배포는 GitHub Actions가 아니라 git pre-push 훅** — main 푸시 = 빌드 + gh-pages 발행
